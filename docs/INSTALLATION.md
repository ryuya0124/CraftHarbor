# インストール・更新・アンインストール

## インストール

GitHub Releasesの`CraftHarbor-0.1.6-win-x64-setup.exe`を実行し、画面に従ってインストールします。Windows x64向けで、.NETランタイムを同梱しています。管理者権限は不要です。

標準の配置先は`%LOCALAPPDATA%\Programs\CraftHarbor`です。スタートメニューの「CraftHarbor」から起動できます。「CraftHarbor をアンインストール」も同じグループに登録します。インストール完了時にアプリやMinecraftサーバーを自動起動しません。

## 既存データと更新

サーバー・ワールド・MOD・設定・バックアップは従来どおり`Documents\CraftHarbor\data`に保存します。ZIP版からインストーラー版へ切り替えても、同じWindowsユーザーならそのまま読み込みます。`CRAFTHARBOR_DATA`環境変数を設定している場合はその保存先を使います。

更新時はCraftHarborを終了して、新しいsetup.exeを実行します。同じインストールとして更新されます。アプリが稼働中ならインストーラーが続行を拒否し、自動終了は行いません。サーバー稼働中にアプリを閉じると影響があるため、プレイが終わってから更新してください。

## アンインストール

Windowsの「設定 → アプリ → インストールされているアプリ → CraftHarbor → アンインストール」、またはスタートメニューのアンインストール項目を使います。

削除するのはインストーラーが配置したアプリ本体・同梱書類・ショートカット・アンインストール登録です。**Documents内のサーバーデータは削除しません。** 再インストールすると同じデータを読み込めます。

以前のZIP展開フォルダやデスクトップのコピー元サーバーは、このインストーラーの管理対象外です。
