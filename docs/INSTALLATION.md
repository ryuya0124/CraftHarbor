# インストール・更新・アンインストール

## インストール

GitHub Releasesの`CraftHelm-0.1.10-win-x64-setup.exe`を実行し、画面に従ってインストールします。Windows x64向けで、.NETランタイムを同梱しています。管理者権限は不要です。

新規インストールの標準配置先は`%LOCALAPPDATA%\Programs\CraftHelm`です。旧版からの更新は従来の配置先を引き継ぎます。スタートメニューの「CraftHelm」から起動できます。「CraftHelm をアンインストール」も同じグループに登録します。インストール完了時にアプリやMinecraftサーバーを自動起動しません。

## 既存データと更新

サーバー・ワールド・MOD・設定・バックアップは従来どおり`Documents\CraftHarbor\data`に保存します。ZIP版からインストーラー版へ切り替えても、同じWindowsユーザーならそのまま読み込みます。`CRAFTHARBOR_DATA`環境変数を設定している場合はその保存先を使います。

v0.1.8以降のインストーラー版は[自動更新](UPDATES.md)に対応します。既定で起動後・24時間ごとに確認し、取得・検証が完了した更新を通常終了後に適用します。手動更新の場合はCraftHelmを終了して、新しいsetup.exeを実行します。同じインストールとして更新されます。アプリが稼働中ならインストーラーが続行を拒否し、自動終了は行いません。アプリから起動したサーバーが稼働中の場合、アプリ自体も終了を拒否します。プレイが終わってサーバーを停止してから更新してください。

## アンインストール

Windowsの「設定 → アプリ → インストールされているアプリ → CraftHelm → アンインストール」、またはスタートメニューのアンインストール項目を使います。

削除するのはインストーラーが配置したアプリ本体・同梱書類・ショートカット・アンインストール登録です。**Documents内のサーバーデータは削除しません。** 再インストールすると同じデータを読み込めます。

以前のZIP展開フォルダやデスクトップのコピー元サーバーは、このインストーラーの管理対象外です。


起動時はローディング画面を先に表示して、設定読み込み後にメイン画面へ切り替わります。インストーラー版ではランタイムをインストール時に配置するため、起動時の自己展開は不要です。起動時間はPC・ディスク・初回のファイル検査などで変わります。

## 名称変更

v0.1.10からCraftHelm（クラフトヘルム）です。新規インストール先は%LOCALAPPDATA%\Programs\CraftHelm、既存インストールは元の場所を使用します。データは引き続きDocuments\CraftHarbor\dataです。実行ファイル名CraftHarbor.exeとインストール識別子は互換性のため保持します。スタートメニューはCraftHelmへ更新し、旧名の起動・削除ショートカットだけを取り除きます。
