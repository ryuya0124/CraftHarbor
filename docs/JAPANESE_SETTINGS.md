# 日本語の設定名と階層

画面上部で大分類、その下で画面を選びます。現在の位置は画面タイトルの下に表示します。

| 大分類 | 画面 |
|---|---|
| 運用 | 概要、コンソール、バックアップ |
| サーバー設定 | 起動・導入、ゲーム・接続、Javaの管理 |
| MOD・プラグイン | 導入・構成、MODの設定、詳細なテキスト編集 |
| アプリ設定 | 表示、更新、接続診断・PC情報、ガイド・保存場所 |

起動・導入は基本情報、Java・メモリ・接続、詳細な起動引数、利用規約・保存、既存サーバーのコピーに分かれます。分類を切り替えても、その画面内で入力した値は保持します。変更後は「利用規約・保存」で保存してください。

ゲーム・接続は基本、参加・権限、負荷・通信、ワールド生成、管理・配布に分類します。検索は全分類を横断します。日本語名を主表示にし、元のキーはツールチップに残します。Minecraft 1.21.1が実際に生成した全設定キーに翻訳があることをテストしています。独自の未登録キーは「追加設定（翻訳未登録）」と原文を表示します。

MODの設定はJSONと単純なTOMLの真偽値・数値・文字列を編集します。JSONの文字列配列は1行ずつ入力します。入れ子やTOMLのセクションは分類ボタンで切り替えます。AutoModpackのサーバー設定と一部の共通項目は日本語名を登録しています。内部バージョンキーDO_NOT_CHANGE_ITは編集対象外です。

**すべてのMOD独自キーの意味を翻訳できるわけではありません。** 未登録の項目・分類は原文を補足し、作者の定義を推測した名前に置き換えません。JSONの複雑な配列・null、TOMLの複数行文字列・複雑な値、JSON5/SNBT/YAML/スクリプトなどは詳細なテキスト編集を使ってください。TOMLに複数行文字列があるファイルはGUI編集対象から外します。数値の構文は検証しますが、MOD独自の範囲・単位・意味は各作者の定義に従います。

GUIはキーや識別子を翻訳して保存しません。編集した値の位置だけを置き換え、未知の値・コメント・未変更の書式を保持します。別の操作でファイルが変わった場合は保存を拒否します。設定は停止中に保存し、通常は次の起動で反映します。

## 稼働中サーバーとアプリ更新

現在はアプリ自身がJavaプロセスとコンソールを管理しているため、サーバー稼働中はアプリの終了・更新適用を拒否します。更新の確認とダウンロードは可能です。遊び終えてサーバーを通常停止し、アプリを終了した後に更新します。

サーバーを起動したまま画面だけ更新するには、独立した管理プロセスと再接続可能な通信へ分離する設計が必要です。現行版には実装していません。今動いているサーバーを無停止で新設計へ引き継ぐことも保証しません。
