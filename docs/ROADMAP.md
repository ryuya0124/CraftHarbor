# ロードマップ

v0.1.0は動作するローカル管理の土台です。以下は将来候補で、実装済み機能ではありません。

## 次の優先項目

1. 実ワールドでの長時間テスト、MOD構成ごとの互換性回帰テスト
2. ページごとのViewModel分割、保存前変更の統一管理、ジョブのサーバー別並列化
3. Forge / NeoForgeインストーラーの自動導入とパック依存版固定
4. Modrinthの既存MOD識別・更新比較・競合検出
5. 定時バックアップ、世代管理、容量見積もり、スケジュール再起動
6. プレイヤー・ホワイトリスト・OP管理画面、Minecraft status ping
7. クラッシュ診断、サーバー単位のCPUグラフ、稼働プロセス再接続
8. コード署名、自動更新、アクセシビリティ・キーボード操作の検証

## 配布サイト

必要になった場合はCloudflare Workersと `craftharbor.ryuya-dev.net` を使用する想定です。本版はGitHub Releasesを配布元とし、サイトやDNS設定を作成・変更していません。

## 拡張候補

CurseForgeはAPIアクセス条件と配布権限を満たす形で検討します。Bedrock・WSL・Docker・遠隔管理はプロセス所有や権限の設計が変わるため、Javaローカル管理と別のアダプターとして扱います。
